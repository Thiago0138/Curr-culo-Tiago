# Tiago Gonçalves — CV online

Site estático (HTML/CSS/JS, sem build) com o currículo de Tiago Gonçalves e o projeto Khora Clothing. Bilingue PT/EN.

## Correr localmente

```bash
npx serve .
```

## Deploy na Vercel

Importar o repositório na Vercel com o preset **Other** — sem comando de build e com o output directory na raiz.

## Editar conteúdo

- Texto em português: `index.html`
- Traduções em inglês: objeto `EN` em `script.js`
- Foto e CV em PDF: `assets/`
